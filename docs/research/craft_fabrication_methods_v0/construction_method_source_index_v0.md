# Construction Method Source Index V0

This index records source anchors for the cross-family construction method
research pass. The repo uses these sources for vocabulary and modeling logic,
not as structural, conservation, safety, or fabrication instructions.

## Source Use Policy

- Use these references for vocabulary, construction sequence, visible anatomy,
  and game-asset logic.
- Do not use them as building-code guidance, structural advice, conservation
  treatment instructions, animal-care guidance, or fabrication-ready shop
  drawings.
- Promote a method to machine-readable taxonomy only after a concrete asset
  family needs it.
