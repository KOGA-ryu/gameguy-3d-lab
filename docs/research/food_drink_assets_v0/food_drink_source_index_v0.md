# Food And Drink Source Index V0

This index records sources used for the food/drink asset lane. The repo uses
these for visible anatomy, broad food categories, serving/storage context, and
modeling vocabulary only.

## Repo Use Rules

- Use sources to name broad forms and serving/storage states.
- Do not copy specific food photos, museum objects, labels, or vessel designs.
- Food safety, nutrition, and recipe claims are out of scope.
- Status tiers are game-readable design lanes, not historical social claims.
- Food/drink assets should read without decals; use silhouette, material roles,
  sockets, and state fields first.
