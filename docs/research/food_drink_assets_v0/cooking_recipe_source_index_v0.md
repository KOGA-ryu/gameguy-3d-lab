# Cooking And Recipe Source Index V0

This index records source anchors for cooking, recipe, kitchen, and preservation
research. The repo uses these sources for game-asset planning, kitchen/pantry
set dressing, readable books, lore hooks, and future source fields.

It does not use them as recipe instruction, food-safety guidance, nutrition
advice, or historical authenticity proof.

## Cooking And Recipe History

| Source | Repo Use |
| --- | --- |
| [Britannica: Cooking](https://www.britannica.com/topic/cooking) | Broad cooking history and vocabulary: heat preparation, roasting, boiling, baking, brewing, winemaking, professional kitchens, class/cuisine effects. |
| [Project Gutenberg: The Forme of Cury](https://www.gutenberg.org/ebooks/8102) | Public-domain medieval English recipe source for recipe-book texture, ingredient names, court-cook status, and manuscript-style lore. |
| [Getty: The Medieval Cookbook](https://www.getty.edu/news/medieval-cookbook-updates-authentic-recipes/) | Medieval recipe presentation context: original Middle English plus modern adaptation, feast/social history, table setting, and etiquette. |
| [British Library: Harley MS 2378](https://searcharchives.bl.uk/catalog/040-002032704) | Manuscript catalogue evidence for mixed medical, culinary, alchemical, dye, pigment, and clothworking recipes in one miscellany. Useful for recipe-book crossover lore. |
| [British Library: Royal MS 18 A VI](https://searcharchives.bl.uk/catalog/040-002107422) | Manuscript catalogue evidence for medical/herbal texts with cookery recipes such as preserves and gingerbread. Useful for kitchen/herbal/apothecary overlap. |

## Preservation And Pantry Method Sources

| Source | Repo Use |
| --- | --- |

| [USU Extension: Drying Foods](https://extension.usu.edu/preserve-the-harvest/drying/) | Drying methods, trays, air circulation, and storage cues useful for racks and dried-food set dressing. |

## Source Use Policy

- Use these references for vocabulary, visible process evidence, source fields,
  kitchen object lists, readable lore hooks, and asset planning.
- Do not copy recipes into gameplay as real-world instructions.
- Do not present these notes as safe preparation, storage, preservation, or
  consumption guidance.
- Promote recipe/cooking data to machine-readable form only when a concrete
  kitchen, pantry, readable book, or food asset needs it.
