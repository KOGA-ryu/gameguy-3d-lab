# Furniture Source Index V0

This index records sources used for the furniture asset lane. The repo uses
these sources for object families, visible anatomy, social-read vocabulary, and
modeling terms only.

## General Furniture

- [Encyclopaedia Britannica, furniture](https://www.britannica.com/topic/furniture)
  - use: movable household equipment, material range, simple-to-elaborate
    status range, wood treatment, decorative processes, furniture kinds
- [V&A, furniture collection](https://www.vam.ac.uk/collections/furniture)
  - use: museum reference context for furniture variety, techniques, and
    collection-oriented style comparison

## Seating

- [Encyclopaedia Britannica, chair](https://www.britannica.com/topic/chair)
  - use: chair as a distinct seating family, with form/status variation

## Tables

- [Encyclopaedia Britannica, table](https://www.britannica.com/topic/table-furniture)
  - use: flat slab supported by trestles, legs, or pillars; medieval trestle
    tables; social significance in halls

## Storage

- [Encyclopaedia Britannica, cupboard](https://www.britannica.com/topic/cupboard)
  - use: cupboard development from boards/display to enclosed door cases,
    shelves, panels, carving, and Gothic motifs

## Beds

- [Encyclopaedia Britannica, bed](https://www.britannica.com/topic/bed-furniture)
  - use: bed furniture as sleeping platform and status-sensitive object family

## Desks and Reading Furniture

- [Encyclopaedia Britannica, desk](https://www.britannica.com/topic/desk)
  - use: specialized reading/writing furniture and desk-family vocabulary

## Joinery

- [Common Woodworking, mortise and tenon](https://commonwoodworking.com/mortise-and-tenon/)
  - use: mortise, tenon, shoulder, and frame-joinery vocabulary for furniture
    anatomy and operator tags

## Repo Use Rules

- Use sources to name visible furniture anatomy and social function.
- Do not copy museum objects, measured plans, ornament patterns, or images.
- Do not claim exact historical authenticity without a later reference packet.
- Treat status/caste tiers as game-readable design lanes, not real-world social
  analysis.
