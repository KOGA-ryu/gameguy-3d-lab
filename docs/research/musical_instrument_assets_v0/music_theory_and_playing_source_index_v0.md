# Music Theory And Playing Source Index V0

This index records source anchors for music-theory and playing-method research.
The repo uses these sources for vocabulary, game-asset planning, readable book
hooks, animation cues, and set dressing. It does not use them as performance
instruction, formal music education, acoustic engineering, or historical
authenticity proof.

## Theory Sources

| Source | Repo Use |
| --- | --- |
| [Open Music Theory](https://viva.pressbooks.pub/openmusictheory/) | Fundamentals vocabulary: notation, clefs, rhythm, scales, modes, intervals, triads, texture, counterpoint, form, orchestration, and classroom-style theory organization. |
| [Music Theory for the 21st-Century Classroom](https://musictheory.pugetsound.edu/mt21c/MusicTheory.html) | Alternate open textbook support for notation, pitch, intervals, rhythm, meter, harmony, form, and analysis categories. |
| [Britannica: Mode](https://www.britannica.com/art/mode-music) | Mode vocabulary, church-mode framing, and non-major/minor tonal worldbuilding. |
| [Britannica: Rhythm](https://www.britannica.com/art/rhythm-music) | Rhythm, beat, time, and meter vocabulary for drums, dance, bells, and animation timing. |
| [Britannica: Melody](https://www.britannica.com/art/melody) | Melody vocabulary for line, contour, phrase, and tune-based readable notes. |
| [Britannica: Harmony](https://www.britannica.com/art/harmony-music) | Harmony vocabulary for chords, vertical sonority, drones, accompaniment, and ensemble texture. |
| [Britannica: Musical Form](https://www.britannica.com/art/musical-form) | Form vocabulary for repeated sections, dance structures, processions, ritual loops, and readable score diagrams. |

## Source Use Policy

- Use these references for vocabulary, visible anatomy, playing cues, readable
  book hooks, and future interaction planning.
- Do not use these notes as formal music lessons, health/ergonomic instruction,
  acoustic engineering, or historical-performance proof.
- Promote theory or playing records to machine-readable data only when a
  concrete asset, animation, lore book, or sound-interaction system needs them.
