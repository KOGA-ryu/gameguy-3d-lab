# Instrument Source Index V0

This index records sources used for the musical-instrument asset lane. The repo
uses these for anatomy names, visible mechanics, and modeling vocabulary only.

## Lute

- [Lute Society of America, What is a lute](https://lutesocietyofamerica.org/about/what-is-a-lute/)
  - use: bowl back, soundboard, neck, pegbox, strings, lute-family vocabulary
- [Encyclopaedia Britannica, lute](https://www.britannica.com/art/lute)
  - use: general lute identity and historical instrument context

## Harp

- [Encyclopaedia Britannica, harp](https://www.britannica.com/art/harp)
  - use: harp as an open-string instrument with neck, soundbox, and strings
- [The Metropolitan Museum of Art, harp collection search](https://www.metmuseum.org/art/collection/search?q=harp)
  - use: visible reference variety for frames, soundboxes, string fans, and
    decorative cases

## Recorder

- [Yamaha, How the recorder works](https://www.yamaha.com/en/musical_instrument_guide/recorder/mechanism/)
  - use: windway, labium, window, tone-hole mechanics, bore behavior
- [Encyclopaedia Britannica, recorder](https://www.britannica.com/art/recorder-musical-instrument)
  - use: recorder identity as an end-blown fipple flute with finger holes

## Shawm

- [Encyclopaedia Britannica, shawm](https://www.britannica.com/art/shawm)
  - use: double reed, conical bore, and flared bell vocabulary
- [The Metropolitan Museum of Art, shawm collection search](https://www.metmuseum.org/art/collection/search?q=shawm)
  - use: visible reference variety for bell shape, body holes, and reed placement

## Frame Drum

- [Encyclopaedia Britannica, drum](https://www.britannica.com/art/drum-musical-instrument)
  - use: membrane stretched over a frame or shell
- [The Metropolitan Museum of Art, frame drum collection search](https://www.metmuseum.org/art/collection/search?q=frame%20drum)
  - use: visible variants with hoops, heads, tacks, jingles, and handheld
    proportions

## Cast Bell

- [Encyclopaedia Britannica, bell](https://www.britannica.com/art/bell)
  - use: bell as a resonant body struck by clapper or striker
- [Whitechapel Bell Foundry](https://whitechapelbellfoundry.co.uk/)
  - use: bellfounding context for cast bells as crafted metal objects

## Portative Organ

- [Encyclopaedia Britannica, organ](https://www.britannica.com/art/organ-musical-instrument)
  - use: pipes, keys, and air supply as organ mechanics
- [The Metropolitan Museum of Art, portative organ collection search](https://www.metmuseum.org/art/collection/search?q=portative%20organ)
  - use: compact organ visual references with pipes, keys, and cases

## Hurdy-Gurdy

- [Encyclopaedia Britannica, hurdy-gurdy](https://www.britannica.com/art/hurdy-gurdy)
  - use: wheel-bowed string identity, crank, and keys
- [GurdyWorld, hurdy-gurdy parts](https://gurdyworld.com/hurdy-gurdy-resources/hurdy-gurdy-parts/)
  - use: wheel, crank, keybox, strings, bridges, tangents, and player-facing
    part vocabulary

## Repo Use Rules

- Prefer visible anatomy over hidden engineering.
- When a source gives broad history, store only the part names and mechanics
  needed for asset planning.
- Do not copy photographs, museum object shapes, measured plans, or ornament
  artwork into repo assets.
- Any final game asset still needs a reference packet before generation work.
