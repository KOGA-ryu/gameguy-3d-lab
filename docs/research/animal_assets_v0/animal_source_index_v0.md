# Animal Source Index V0

This index records external source pages used as support for starter animal
asset planning. The pages are not copied into the repo; they provide reference
terms for visible anatomy, body type, and role grouping.

## General Reference

| Source | Repo Use |
| --- | --- |
| [Britannica - Animal](https://www.britannica.com/animal/animal) | General animal grouping language and broad biology context. |
| [Britannica - Mammal](https://www.britannica.com/animal/mammal) | Mammal grouping for dogs, cats, equines, livestock, bats, rodents, deer, and wolves. |
| [Britannica - Bird](https://www.britannica.com/animal/bird-animal) | Bird grouping for poultry and corvid body-plan notes. |
| [Britannica - Fish](https://www.britannica.com/animal/fish) | Fish body planning: fins, tail, streamlined body, and aquatic use. |
| [Britannica - Reptile](https://www.britannica.com/animal/reptile) | Reptile grouping context for snakes. |
| [Britannica - Amphibian](https://www.britannica.com/animal/amphibian) | Amphibian grouping context for frogs and toads. |

## Repo Policy

- Use these pages as reference support, not as final art direction.
- Every promoted animal still needs a reference packet before modeling.
- Do not use this index as animal-care guidance, welfare advice, or proof of
  biological accuracy.
