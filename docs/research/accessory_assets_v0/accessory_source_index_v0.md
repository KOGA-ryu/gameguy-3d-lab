# Accessory Source Index V0

This index records sources used for the accessory asset lane. The repo uses
these for visible anatomy, broad accessory families, and craft/status vocabulary
only.

## Fashion And Personal Accessories

- [V&A fashion accessories](https://www.vam.ac.uk/collections/fashion-accessories)
  - use: broad category support for belts, bags, purses, and wearable personal
    accessories

## Repo Use Rules

- Use sources to name visible parts and broad object roles.
- Do not copy museum object designs, images, measured plans, or ornament.
- Treat status tiers as game-readable design lanes, not real-world social claims.
- Keep attachment sockets explicit so accessories can become wearable, lootable,
  or static clutter later.
