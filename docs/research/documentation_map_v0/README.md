# Documentation Map V0

This folder tracks documentation still needed before the repo returns to focused
3D asset generation.

It is not a build queue. It is a subject and documentation-coverage map.

## Documents

- `repo_documentation_needs_v0.md` defines the documentation layers every major
  asset family should eventually have.
- `asset_subject_potential_map_v0.md` expands the subject map across
  architecture, props, materials, creatures, tools, lore, and world systems.
- `documentation_backlog_v0.md` lists next documentation packets by priority and
  explains why each packet matters.
- `global_style_atlas_v0.md` defines environment-level style languages such as
  cathedral Gothic, castle fortress, village, market/tavern, crypt dungeon,
  cave, sewer/cistern, ruin, workshop, noble interior, wilderness shrine, and
  mine/quarry.
- `shape_language_dictionary_v0.md` gives practical words for mass, edge,
  molding, panel, arch, tracery, sacred geometry, organic ornament, wear, and
  assembly changes.

## Boundary

This lane does not promote assets into recipes, run Blender, create generated
meshes, or decide final art direction. It exists so future asset work has a
human-readable map instead of scattered lists.
