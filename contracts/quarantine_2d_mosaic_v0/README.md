# Quarantined 2D Mosaic Contracts

These contracts were present in the Mac prototype baseline, but they describe 2D mosaic tiles, Met mosaic panel tile families, or example floor-fill/medallion/border output records.

They are quarantined instead of deleted so the first cleanup pass can preserve context while removing them from the active contract root.

Do not use this folder as source for new 3D architecture, terrain, building, connector, geometry, measurement, or workflow work. If a future task needs one of these records, promote it deliberately with a new scope decision.
