# Folder Ownership

This repo is the 3D architecture, terrain, map graph, connector, and Blender proof-script lab. Folder ownership is source-oriented: generated proof outputs and media artifacts should not be added here unless a later task explicitly promotes a small fixture as source.

## Active Source Folders

- `contracts/`: schema-like contracts for 3D architecture, map, terrain, connector, measurement, geometry, and workflow records.
- `data/architecture/`: authored architecture, terrain, map, connector, and measurement source data.
- `geometry_dictionary/`: legal geometry, profile, operation, connector, measurement, semantic, and validation terms.
- `docs/research/`: local research notes that support architecture measurement, map generation, and terrain tile/seam decisions.
- `scripts/`: Python prototype compilers, validators, and Blender proof scripts for 3D/map/building workflows.
- `workflow/`: work orders, decisions, and reports for this lab.

## Generated Or Excluded Lanes

- Do not add `pattern_lab_2d/`.
- Do not add 2D ornament generation, Aseprite, mosaic tile export, or 2D contact-sheet lanes.
- Do not add render, media, mesh, or Blender proof output files.
- Do not add generated `goal/architecture/blender_tests/` or `goal/receipts/` output as source.

## Claims

This repo does not make production, structural, fabrication, historical accuracy, gym/museum approval, or game-engine integration claims.
